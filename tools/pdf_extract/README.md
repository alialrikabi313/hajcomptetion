# استخراج الأسئلة من ملفات المصدر (PDF)

هذه الأدوات تبني `assets/haj_questions.json` نقلاً حرفياً من ملفات الـPDF
الموجودة في `assets/` (ملفات دائرة الإرشاد + ملف مدارك أجوبة أسئلة المرشدين).

## لماذا؟

ملفات الـPDF لا تحتوي نصاً قابلاً للنسخ: خريطة `ToUnicode` فيها معطوبة، فأي
نسخ مباشر يعطي حروفاً مشوّشة. لذلك يفكّ `pdftext.py` النص من الخطوط نفسها:

1. يقرأ معرّف الرسمة (glyph id) لكل حرف من `get_texttrace()`.
2. يعكس `cmap` الخط المضمّن للحصول على شكل الحرف (presentation form).
3. يفكّ الرباطات (GSUB: ligature / single / alternate / multiple).
4. يعيد الحركات (التشكيل) إلى حروفها حسب مواضعها الأفقية.
5. يعيد ترتيب الأرقام والحروف اللاتينية (التي تُخزَّن بترتيب بصري).

## الخطوات

```bash
python decode.py        # (الخطوة داخل build.py أدناه) → txt/*.json نص مفكوك مع مواضع الأسطر
python extract2.py      # ملفات المواضيع الأحد عشر  → pdf_questions.json
python extract_madrak.py# ملف مدارك الأجوبة ١٤٤٧    → madrak_questions.json
python build.py         # يبني بنك الأسئلة النهائي   → new_bank.json
python compare2.py      # يقارن البنك الحالي بالمصدر ويطبع الفروق
python batch.py list.json "out%d.png" 3   # يصوّر أسئلة معيّنة من الـPDF للمراجعة بالعين
```

## overrides.json

مواضع نادرة يكون فيها المصدر نفسه مشوّشاً (خيارات مكتوبة فوق بعضها، أو رقم
خيار مطبوع «١» بدل «أ»). كل عنصر مفتاحه `اسم الملف|رقم السؤال` وقيمته النص
الصحيح كما يظهر في الصفحة المطبوعة (تم التحقق منه بالنظر إلى الصورة).

## التدقيق (ثلاثة مسارات مستقلة)

```bash
python selfcheck.py       # مطابقة حرفية: يعيد تركيب كل سؤال ويقارنه بأسطر المصدر
python verify_answers.py  # يقص سطر «الجواب الصحيح» لكل سؤال ويقرأه بـ tesseract
python answer_sheets.py   # يجمع الأسطر التي عجز عنها المحرك في صور تُقرأ بالعين
python verify.py          # قراءة ضوئية لكتلة السؤال كاملة (فيها ضوضاء، للفرز فقط)
```

`selfcheck.py` هو الأهم: يبني من أسطر المصدر النصَّ المتوقَّع بعد إسقاط ما يسقطه
المحلل (رقم السؤال، حروف الخيارات، صدر «الجواب الصحيح هو الأول»)، ثم يقارنه حرفاً
بحرف بما في التطبيق. أي حرف زائد أو ناقص يظهر في التقرير.

## قواعد ثابتة

- الجواب الصحيح يؤخذ من سطر «الجواب الصحيح هو الأول/الثاني/…» ويُطابق **حرف**
  الخيار (أ ب ج د) لا ترتيب ظهوره في الصفحة.
- إن لم يذكر المصدر جواباً (أو نصّ على أنه «لا يوجد جواب صحيح ضمن الخيارات»)
  فالسؤال لا يُدرج في التطبيق.
- المستند = بقية سطر الجواب بعد كلمة الترتيب، مع الهوامش المرتبطة بالسؤال.
