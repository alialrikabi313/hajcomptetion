# حج المسابقات (Hajj Competitions)

> Hajj-themed quiz competition application built with Flutter — combining Islamic education with engaging gamification mechanics for Arabic-speaking users.

[![Flutter](https://img.shields.io/badge/Flutter-3.x-02569B?logo=flutter&logoColor=white)](https://flutter.dev)
[![Dart](https://img.shields.io/badge/Dart-3.x-0175C2?logo=dart&logoColor=white)](https://dart.dev)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

---

## ✨ Features

- 🏆 **Multi-level quiz system** with Hajj and Islamic-knowledge questions
- ⏱️ **Timed challenges** with difficulty progression
- 📊 **Score tracking and leaderboards**
- 🎨 **Polished, animated UI** built for engagement
- 📱 **Full Arabic RTL** experience
- 🎯 **Educational design** — questions are reviewed for accuracy
- 🔊 Sound effects and haptic feedback for immersion

---

## 🛠️ Tech Stack

| Layer | Technology |
|-------|-----------|
| Framework | Flutter 3.x / Dart |
| State Management | Provider |
| Storage | Local persistence with SharedPreferences |
| Localization | Arabic-first, RTL UI |

## 📦 Getting Started

```bash
git clone https://github.com/alialrikabi313/hajcomptetion.git
cd hajcomptetion
flutter pub get
flutter run
```

**Requirements:** Flutter SDK 3.x, Dart 3.x.
